# 💬 Lumina Chat: Premium Real-Time Communication Platform

Lumina Chat is a high-performance, full-stack communication platform built for speed, security, and a premium user experience. Featuring a stunning **Glassmorphism UI** and a robust **MERN architecture**, this application is designed to be a production-ready foundation for any modern SaaS product.

---

## 💎 Key Features for Investors

- **Real-Time Engine**: Built with Socket.io for sub-100ms latency messaging and presence tracking.
- **Intelligence Hub**: Integrated media management system for seamless image and file sharing.
- **Premium Aesthetics**: Sophisticated Violet/Indigo design system with modern glassmorphism effects and responsive mobile-first layouts.
- **Secure Authentication**: Industry-standard JWT-based auth with encrypted password hashing.
- **Modular Architecture**: Clean, scalable codebase organized for rapid deployment of new features.

---

## 🛠️ Tech Stack & Infrastructure

- **Frontend**: React 18, Tailwind CSS (Custom Indigo/Violet Theme)
- **Backend**: Node.js & Express.js
- **Database**: MongoDB (Optimized Aggregation Pipelines)
- **Real-Time**: Socket.io (Bi-directional communication)
- **Media Storage**: Cloudinary Integration
- **State Management**: Optimized React Context API
- **Security**: JSON Web Tokens (JWT) & bcrypt

## 🚀 Getting Started

### Prerequisites
- Node.js (v16+)
- MongoDB Atlas Account
- Cloudinary Account

### Installation

1. **Clone the Repository**
   ```bash
   git clone [repository-url]
   cd Chat_app
   ```

2. **Backend Setup**
   ```bash
   cd server
   npm install
   # Create a .env file with:
   # MONGODB_URI=your_uri
   # JWT_SECRET=your_secret
   # CLOUDINARY_CLOUD_NAME=your_name
   # CLOUDINARY_API_KEY=your_key
   # CLOUDINARY_API_SECRET=your_secret
   npm start
   ```

3. **Frontend Setup**
   ```bash
   cd client
   npm install
   npm run dev
   ```
